Finanzas en R

Una guía metodológica para tu aprendizaje

¿Qué encontrarás en este repositorio?

Este es tu espacio de aprendizaje para dominar tres habilidades clave en finanzas cuantitativas: simulaciones de portafolios, análisis de datos reales, y extracción automática de información de documentos PDF. Todo usando R, un lenguaje diseñado precisamente para este tipo de análisis.

1. Estructura del Repositorio

Tu repositorio está organizado en tres núcleos de aprendizaje, cada uno enfocado en una metodología diferente pero complementaria:

📊 project-simulation

Tema: Análisis de Portafolios Financieros

Propósito: Simular retornos de inversiones y evaluar riesgo

Aquí aprendes a construir modelos financieros desde cero: cómo generar datos, simular escenarios futuros (Monte Carlo), y calcular métricas de riesgo como volatilidad y Value-at-Risk (VaR).

🔍 project-ocr

Tema: Extracción de Datos de Documentos PDF

Propósito: Automatizar la lectura y limpieza de datos

Aquí aprendes a usar Optical Character Recognition (OCR) para extraer tablas de PDFs, limpiar datos "sucios" del mundo real, y exportarlos en formatos listos para análisis.

🎯 Archivos iniciales

Tema: Fundamentos de R

Propósito: Aprender sintaxis básica y operaciones fundamentales

Scripts simples como hello_world_*.R te introducen a la programación en R: variables, funciones, estructuras de control.

2. Project-Simulation: Análisis de Portafolios

Metodología Clave: Simulación de Monte Carlo

Genera miles de escenarios de retornos posibles para estimar el riesgo de una cartera de inversiones.

¿Qué aprenderás?

  • Conceptos Financieros: Retorno, volatilidad, correlación, diversificación
  • Técnicas Estadísticas: Simulación de variables aleatorias, distribuciones
  • Visualización: Cómo representar resultados de forma clara e interpretable

project-simulation-part01-comentado.R

Tu punto de partida. Este archivo:

3. Project-OCR: Extracción y Limpieza de Datos

Metodología Clave: ETL (Extract, Transform, Load)

El ciclo completo de preparación de datos: extrae información de fuentes no estructuradas, limpia inconsistencias, y exporta en formato analítico.

¿Qué aprenderás?

  • Extracción de Texto: OCR con pdftools y tesseract
  • Manipulación de Strings: Expresiones regulares y limpieza de caracteres
  • Transformación de Datos: Conversión de tipos, validación, detección de errores
  • Exportación: CSV, RDS, y otros formatos

Progresión de Scripts

ocr-pdf-01.R Básico

Extracción simple del PDF de USBP (US Border Patrol). Aquí ves cómo:

  • Leer un PDF con pdf_text()
  • Dividir texto en líneas y campos
  • Separar datos por espacios múltiples
  • Convertir a data.frame
ocr-pdf-02.R Intermedio

Limpieza y validación completa. Aprendes:

  • Eliminar filas vacías y artefactos del PDF
  • Limpiar nombres (asteriscos, paréntesis)
  • Clasificar filas (sectores vs. totales)
  • Convertir columnas a tipos numéricos
  • Validar integridad: Verificar que subtotales cuadren
ocr-pdf-03.R Avanzado

Análisis y visualización de datos limpios (ejemplo: análisis exploratorio).

El Dataset Real: USBP Sector Profile FY2017

Trabajas con datos reales del Patrullaje Fronterizo de EE.UU. La tabla incluye:

  • 20 sectores fronterizos (Miami, El Paso, San Diego, etc.)
  • 4 subtotales regionales (Coastal, Northern, Southwest, Nationwide)
  • 9 métricas: personal, aprehensiones, drogas decomisadas, etc.
⚠️ Desafío Real: El PDF original tiene:
  • Números con comas ("2,280" → 2280)
  • Valores "N/A" que deben convertirse a NA en R
  • Asteriscos indicando notas al pie
  • Inconsistencias en formato entre páginas
Tu script debe manejar todo esto automáticamente.

Resultado Esperado

Después del pipeline completo tendrás:

  • usbp_sector_profile_fy2017.csv - Tabla limpia en formato CSV
  • usbp_sector_profile_fy2017.rds - Almacenamiento eficiente para R
  • Validaciones que prueban integridad de datos ✓
  • Documentación de qué cambios se hicieron y por qué

6. Preguntas Guía Mientras Aprendes

Para project-simulation:

  • ¿Qué es volatilidad? ¿Cómo la calculamos?
  • ¿Por qué simulamos 10,000 escenarios y no solo uno?
  • ¿Qué significa "correlación negativa"? ¿Por qué importa para diversificar?
  • ¿Cómo interpretamos un gráfico de distribuciones de retornos?
  • ¿Qué es Value-at-Risk (VaR) al 95%? ¿Qué nos dice?

Para project-ocr:

  • ¿Qué es OCR y cuáles son sus limitaciones?
  • ¿Por qué algunas columnas quedan como texto si contienen números?
  • ¿Cómo detectamos filas mal formateadas o faltantes?
  • ¿Qué significa "validación de datos"? ¿Cómo la implementamos?
  • ¿Cómo documentamos qué transformaciones aplicamos?
